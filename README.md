# Boss 公司名称采集脚本 v1.1.1

## 更新方式

[GitHub 仓库](https://github.com/wuy705464-ai/boss-company-crawler) · [安装 / 更新脚本](https://raw.githubusercontent.com/wuy705464-ai/boss-company-crawler/main/boss_company_crawler.user.js)

安装 Tampermonkey 后，打开上面的安装链接并在油猴页面确认安装或更新。v1.1.1 新增 GitHub 安装及自动更新地址，采集逻辑与已验证的 v1.1.0 一致。后续版本可通过油猴的更新检查获取。

在油猴管理面板中编辑原来的“Boss直聘-公司名批量导出”，将 `boss_company_crawler.user.js` 的全部内容替换进去，保存并刷新 Boss 职位搜索页。建议更新现有脚本，避免两个版本同时启用。

下载仓库中的文件不会自动更新油猴中已经安装的脚本，请通过安装链接更新，或在油猴中替换代码。

## 使用

1. 在网站正常登录、搜索并设置城市和筛选条件，等职位卡片加载完成。
2. 检查采集面板显示的关键词和城市代码。自动采集读取当前网址的查询参数，从第 1 页开始；不会再固定搜索“金华·外贸业务员”。
3. 点击“开始 / 继续”，默认每轮最多 20 页，可调整为 1–100 页。点击“暂停”可中止请求和等待；刷新后保持暂停，再点击继续。
4. 页面筛选条件若没有体现在网址里，使用“采集当前页”。手动翻页后可再次采集，数据自动去重；此按钮不会改变自动采集的页码。
5. 点击“导出 CSV”。第一列为公司显示名称，另外包含采集来源、搜索页面和首次采集时间，可用 Excel 打开。

“从头重扫”重置当前搜索的页码，保留已有公司，适合搜索结果更新后重新收集。“清空当前搜索”只删除该搜索的数据。每种网址搜索条件的进度独立保存。

旧版记录仍保留在旧存储项，可通过“导出旧版数据”单独导出。旧版 API 失败时可能反复记录当前页面，因此新版不继承旧页码，也不把无法确认来源条件的旧记录混入新搜索。

## 本次修复

- API 出错立即停止，避免原脚本反复读取同一个 DOM 页面却增加页码。
- 暂停时取消请求和等待；迟到响应不能污染重启、清空或切换搜索后的结果。
- 按当前网址参数隔离采集数据；采集时直接去重。
- 20 秒请求超时、空页结束、`hasMore` 末页判断、重复职位页检测、单次页数限制和总计 500 页上限。
- 优先使用接口 `companyName`，缺失时使用 `brandName`；DOM 同时检查链接和父元素的 title，过滤字面省略号。
- 修复完成或报错提示被面板重绘覆盖的问题；增加可折叠面板。
- CSV 保留中文 BOM、正确转义引号及换行，并对可能被 Excel 当公式执行的字段加前缀。
- 保存失败停止采集并回滚页码，当前内存中已读到的名称仍可导出。

## 验证与边界

已通过 Node.js 语法检查和 17 项离线回归测试，覆盖暂停重启、清空后迟到响应、搜索切换、重复页、超时、保存失败恢复、旧数据保留及 CSV 等场景。

本版本尚未进行 Boss 登录会话下的线上实测。接口是否仍接受这些参数、页面选择器是否匹配当前布局，需要在实际网站确认。离线测试使用模拟响应和简化 DOM，不等同于油猴浏览器实测。

接口登录/验证/限流错误会停止，不会自动反复请求或回退采集。请先在网站正常处理登录或验证；需要时再手动继续。

公司显示名称可能是品牌名或简称，不是工商全称核验结果。翻页期间搜索结果也可能变化，不能保证完整穷尽所有公司。建议同一时间只在一个标签页使用本脚本；多个标签页同时写入油猴存储尚未做并发合并。
