# Boss 工商公司名称采集 v1.3.0

[安装 / 更新油猴脚本](https://raw.githubusercontent.com/wuy705464-ai/boss-company-crawler/main/boss_company_crawler.user.js)

## 用途

职位列表可能只显示品牌名、简称或被省略的名称。v1.3.0 从当前列表建立任务，逐个进入职位详情页，从“工商信息 → 公司名称”读取完整名称。

例如本次浏览器实测中，列表显示“鸿鹄”，职位详情页的工商信息显示“金华鸿鹄网络信息有限公司”。脚本同时保留两列，避免把简称冒充工商全称。

## 使用方法

1. 打开安装链接更新脚本并刷新 Boss 页面，面板标题应为 **工商公司名采集 v1.3.0**。
2. 在 Boss 选择地区、关键词和其他筛选条件，等待职位列表加载。
3. 如果只需要义乌市，在“地址包含”填写 `义乌市`；留空则扫描当前列表的所有职位。
4. 点击“扫描当前列表”。脚本从每张职位卡片保存职位详情链接和公司链接，同一公司按公司链接去重。
5. 设置“本轮最多”，建议先用 5 家验证。点击“开始工商补全”。脚本会逐个进入职位详情页，读取工商公司名称，每家间隔 6–10 秒。
6. 本轮完成后自动返回原职位列表。继续滚动或翻页，再次扫描和补全即可。
7. 点击“导出工商全称”只导出成功记录；“导出本搜索全部”还包含待处理、失败和旧版简称，便于检查遗漏。

批量运行时不要关闭当前标签页。可以在脚本面板点击“暂停”；中断项会保留，通过“重试失败项”放回队列。若进入网站验证页面，请按网站正常流程处理，脚本不会绕过验证。

## 数据与迁移

- CSV 包含列表公司名、工商公司名称、状态、职位地区、公司链接、职位链接、搜索页面和时间。
- v1.2 及更早版本的简称记录继续保留。旧记录本身没有职位链接，只有同名公司重新出现在当前列表并被扫描后，才能补上链接进入工商队列。
- 同一搜索页面的数据按网址参数保存。某些 Boss 筛选不体现在网址中，建议更换筛选前先导出当前结果。
- 建议同一时间只在一个标签页运行；多个标签页同时写入尚未实现并发合并。

## 验证与边界

- 浏览器实测确认 Boss 职位详情页直接包含工商公司名称，且列表卡片同时提供职位详情链接和公司链接。
- 13 项离线回归测试覆盖工商字段解析、地区过滤、公司链接去重、旧数据升级、批次上限、导航、暂停、验证识别、失败重试、保存失败和 CSV。
- 完整浏览器模拟验证通过：扫描列表 → 进入职位详情 → 读取工商名称 → 返回列表，计数从工商成功 0 变为 1。
- 尚未执行真实 Boss 批量跑完测试；网站可能触发登录或安全验证，页面结构变化也可能需要再次适配。
- 工商名称来自 Boss 当前展示内容，没有连接国家企业信用信息公示系统做二次核验。
