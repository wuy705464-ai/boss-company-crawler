# Boss 公司名称采集 v1.2.0

[安装 / 更新油猴脚本](https://raw.githubusercontent.com/wuy705464-ai/boss-company-crawler/main/boss_company_crawler.user.js)

## 这次修复什么

旧版直接调用的职位接口返回 HTTP 404，却统一显示“检查登录或验证”，容易误导。新版移除了直接接口请求，改为收集职位页面已经加载出来的公司名称。

新版 /web/geek/jobs 页面的网址可能不包含城市和关键词。脚本现在以实际页面结果为采集对象，不再要求网址必须有这些参数，也不再显示虚假的 API 页数。

## 使用方法

1. 安装 Tampermonkey，打开上方链接，在油猴页面确认更新。刷新 Boss 页面后，应看到面板标题 **v1.2.0**。
2. 在 Boss 页面选择地区（例如金华、义乌）和需要的关键词，等职位卡片加载。
3. 点击“采集当前页”可收集已经加载的公司；点击“开始采集”会持续收集新出现的公司并去重。
4. 默认每 5 秒向下滚动一次。可以取消“自动向下滚动加载结果”，改为自己浏览、滚动或翻页，脚本继续收集。不自动点击下一页按钮。
5. 45 秒没有新职位变化时会暂停，这不代表采集完网站全部结果。手动翻页或调整位置后，可再次开始。
6. 点击“导出 CSV”。第一列是公司显示名称，另外包含采集来源、页面地址和首次采集时间。

页面弹出可识别的登录/验证窗口时会暂停，请在网站正常处理。改动筛选条件时建议先暂停，等结果刷新后继续。选择器未覆盖的筛选控件无法保证自动暂停。

## 数据保存

公司名称在油猴本地存储中保存；刷新后不会自动开始。按网址搜索参数分组，**网址不变的筛选结果会合并保存**；若要分开导出，请先导出、清空当前搜索，再更换条件。

“导出全部历史”包含新版、v1.1.x 以及 v1.0 的可读取记录并去重。“清空当前搜索”只清理当前组。旧版存储项仍保留。

建议一次只在一个标签页运行，多个标签页同时写入尚未实现并发合并。

## 验证与限制

- 18 项离线回归测试及语法检查通过：无参数新版路由、隐藏/截断名称、动态新增、暂停重启、清空、存储失败恢复、搜索切换、验证窗口、停止条件、自动滚动和 CSV。
- 在浏览器本地模拟职位页面验证公司采集和动态追加；模拟数据不是真实 Boss 结果。
- 已观察到登录后的新版 /web/geek/jobs 页面，但检查标签页随后多次变为空白，未完成真实 Boss 公司采集验证。页面布局变化仍可能需要适配。
- 公司名称可能是品牌名或简称，不保证工商登记全称，也不保证穷尽所有公司。
